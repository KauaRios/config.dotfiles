# Sora

Composição original escrita para estas dotfiles: três painéis, relógio central preenchido pela cor principal, workspaces com estado ativo alongado, mídia à esquerda e grupos discretos de saúde/conectividade à direita. Altura de 42px e fonte de 14px, sem depender de Nerd Fonts.

A temperatura da CPU permanece visível. Clique no losango para abrir o Rofi; na música para pausar/continuar e com o botão direito para abrir Spotify. Clique no relógio para alternar data/hora e no perfil de energia para alterná-lo. O sensor de temperatura usa o caminho do Ryzen deste computador.

`colors.css` separado acompanha a paleta dinâmica. Nenhum pacote novo ou script de coleta foi adicionado neste modelo. Reutiliza os módulos e comandos que já fazem parte destas dotfiles.

## Inspirações visuais pesquisadas

- [My first rice, de iotovic](https://www.reddit.com/r/unixporn/comments/1olgyf0/hyprland_my_first_rice/): comentários elogiam os módulos arredondados e a simplicidade.
- [What do you think?, de Ambitious-Gur-6433](https://www.reddit.com/r/unixporn/comments/1n0if4i/hyprland_what_do_you_think/): inspiração no contraste entre painéis escuros e detalhes suaves.

São exemplos de preferências da comunidade, não um ranking. Nenhum arquivo de configuração ou folha de estilo desses autores foi copiado; o JSON e o CSS foram escritos para este modelo.

Selecione **sora** em Super+Shift+R. Não aplicado automaticamente. JSON e CSS GTK verificados; não houve avaliação visual na sessão gráfica.
