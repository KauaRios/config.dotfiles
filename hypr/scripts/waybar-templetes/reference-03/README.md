# reference-03

Referência: `reference3.png` na raiz do repositório. Layout baseado na captura, com escala ajustada para texto legível. A paleta acompanha o wallpaper: o laranja/creme da referência vira a cor de destaque atual.

`colors.css` é separado e aponta para a paleta ativa. O seletor copia apenas config/style.css. Não copie esse link para a pasta ativa.

Os valores de volume, memória, CPU, rede e bateria são reais. O texto de mídia vem de MPRIS; só aparece com um player compatível. O título depende da janela focada. Bandeja e estados dependem dos programas ativos. Não há forma de onda de áudio simulada: a primeira referência usa um visualizador que não foi adicionado aqui. Os glifos Unicode substituem ícones específicos não fornecidos pelas imagens. OMARCHY é apenas o rótulo visual das duas primeiras referências, sem instalar componentes desse ambiente.

Não aplicado à sessão. Validação de JSON/módulos e CSS GTK não garante equivalência pixel a pixel; fonte, DPI, resolução e conteúdo alteram o resultado. Use Super+Shift+R para selecionar quando desejar.
